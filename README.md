# LinkedIn Zip Solver

An automated browser extension designed to solve LinkedIn's **Zip** puzzle game efficiently.

## 📌 Features

- **Automated Solving:** Parses the game grid and computes solutions automatically.
- **Chrome Extension UI:** Clean popup interface to trigger and manage solving actions.
- **DOM Interaction:** Direct interaction with LinkedIn's puzzle interface to execute moves automatically.

## 📁 Repository Structure

- `manifest.json`: Extension configuration and permissions.
- `popup.html` & `popup.js`: User interface and script logic for the extension popup.
- `solver.js` & `solver_bundle.js`: Main logic for computing game solutions.
- `dom.js`: Helper script for inspecting and manipulating page DOM elements.
- `util.js`: Utility functions and helper algorithms.
- `zip.js`: Specific game board parser and rules engine.
