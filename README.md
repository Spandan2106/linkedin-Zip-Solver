# LinkedIn Zip Solver 🧩

[![GitHub stars](https://img.shields.io/github/stars/Spandan2106/linkedin-Zip-Solver?style=social)](https://github.com/Spandan2106/linkedin-Zip-Solver/stargazers)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**LinkedIn Zip Solver** is a browser extension designed to automate and simplify solving location/zip challenges on LinkedIn. 

---

## 🚀 Features

* **Automated Solving:** Streamlines the process of clearing zip/location verification prompts on LinkedIn.
* **Lightweight & Fast:** Built with modern JavaScript and clean architecture to ensure minimal resource consumption.
* **Easy Integration:** Seamlessly runs as a browser extension using a popup interface and dedicated background scripts.

---

## 📁 Project Structure

```text
linkedin-Zip-Solver/
│
├── dom.js             # DOM manipulation and interaction scripts
├── manifest.json      # Extension manifest configuration
├── popup.html         # Extension popup user interface
├── popup.js           # Popup interaction logic
├── solver.js          # Core solver logic
├── solver_bundle.js   # Bundled solver script for production
├── util.js            # Helper and utility functions
└── zip.js             # Zip code processing modules
```
**🛠️ Installation & Setup**
1. * Clone or Download this repository to your local machine:

```Bash
git clone [https://github.com/Spandan2106/linkedin-Zip-Solver.git](https://github.com/Spandan2106/linkedin-Zip-Solver.git)
```
2. * Open your browser (Google Chrome or compatible Chromium-based browsers) and navigate to your extensions page (```chrome://extensions/```).

3. * Enable Developer mode using the toggle in the top-right corner.

4. * Click Load unpacked in the top-left corner and select the cloned ```linkedin-Zip-Solver``` folder.

5. * The extension should now appear in your toolbar and be ready for use!
